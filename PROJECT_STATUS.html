씨름 로봇 ROS2 코드 구현 현황

작성 기준: 현재 코드 폴더의 파일을 기준으로 정리한 문서입니다. 하드웨어를 이 환경에서 직접 실행한 결과가 아니라, 소스 구조와 ROS2 연결을 기준으로 판단했습니다.

현재 실제 실행 구성

motor_node.py + vision_node.py + color_node.py + test_code_hfsm_modular.py + switch_node.py를 실행합니다. modular Brain의 실제 구현은 hfsm_brain/ 폴더에 있습니다.

현재 Brain은 스위치가 켜져야 동작하며, 정지 명령은 모터 Hard Stop 서비스 대신 0 속도의 Twist를 반복 발행하는 Soft Stop으로 처리합니다. 벽이 가까우면 초록색보다 벽 회피를 먼저 선택합니다.

행동 우선순위

  1. 스위치가 OFF이면 모든 행동 대신 Soft Stop을 보냅니다.
  2. 벽이 가까우면 초록색과 컬러 센서보다 먼저 벽 회피를 실행합니다.
  3. 벽이 없고 초록색이 보이면 Green_Follow_Action으로 추격합니다.
  4. 초록색이 없으면 색상 패턴표에 따라 센서 행동을 선택합니다.
  5. 해당하는 특수 패턴이 없으면 벽이 없을 때 Cruise_Action으로 기본 직진합니다.

현재 실행 경로에서는 카메라의 red_between_green 기능을 삭제했기 때문에, 초록색과 카메라 사이의 빨간색을 별도 신호로 판단하지 않습니다. 컬러 센서의 빨간색 패턴은 그대로 사용합니다.
